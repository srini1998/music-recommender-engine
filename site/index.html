        Credits & small print

        Data

        Listener identities never leave the build machine: user names are dropped and ids salted during extraction; this page only ships per-artist aggregates (listener counts, co-listener counts ≥ 3, genre weights).

        How it scores

        Co-listening: item-kNN cosine over which artists the same listeners played, shrunk by co/(co+5). Genre match: TF-IDF cosine between your seeds' combined MusicBrainz genre profile and each artist. Novelty multiplies relevance by (1 − β·log-popularity). Diversity is maximal-marginal-relevance re-ranking of the top 150 in genre space.

        Limits

        • One day of listens from people who chose to use ListenBrainz — not a representative audience, and skewed to rock/indie.
        • Artists, not tracks. No audio is analysed; no playback.
        • Offline recall on hidden halves of real histories, not a user study. "Novelty" is a statistic, not taste.
        • Metrics are precomputed on a grid; the live chart snaps to the nearest grid point.

        The earlier version of this repo (biased matrix factorisation on an authored toy catalog) is preserved in src/recommender.py; it is not what runs here.
